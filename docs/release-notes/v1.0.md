# Typeshala v1.0 — Release notes

**Version**: 1.0.0
**Date**: 2026-09-16
**Systems**: Windows, macOS, Linux (Tauri bundler, `bundle.targets: all`)

## What is new

- English touch typing tutor with live WPM plus accuracy and finger guidance
- Structured lessons with progression, best scores, and unlock rules
- Nepali Romanized layout (familiar keys, Unicode output)
- Nepali Traditional Preeti layout (conjunct and matra sequences)
- Progress trends and stats screen (WPM trend, accuracy trend, lessons done)
- Settings for layout, UI language (English plus Nepali), theme, sound, prompt size
- Bonus Ramayana falling words game (scores kept apart from lessons)
- Offline first launch with safe defaults; corrupt store recovers with backup plus notice

## Install

Run the installer for your system from the release bundle. No network needed.
Lessons are embedded in the app. Progress and settings stay on your device.

## Notes

- Stored shapes stay at schema version 1; no migration in this release.
- No accounts, no cloud sync, no network calls.
- Updates arrive by reinstall; no auto updater in this slice.
