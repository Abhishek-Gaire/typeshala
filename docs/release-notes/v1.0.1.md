# Typeshala v1.0.1 — Release notes

**Version**: 1.0.1
**Date**: 2026-10-01
**Systems**: Windows, macOS, Linux (same bundle set as v1.0)

## What is new

- Rare Nepali letters now score as one letter each. `ट्ट`, `द्व`, `हृ`, `रू`, `ह्र` and
  nine more rare conjuncts used to be counted as two to four letters when scored.
  They now count once, the same way every other letter in the layout does. The keys
  you press are unchanged, so nothing about how you type them has changed.
- All Level 1 Traditional gained three tokens built around `ट्ट`, `द्व`, and `हृ`, each
  repeated thirty times, so a three key spelling gets enough practice. Note that this
  screen is no longer purely cross row key practice.
- Guidance steps through every key of a three key letter, for example `6` then `\`
  then `6` for `ट्ट`, with the remaining keys shown as a hint.

## Fixed

- Fixed a problem where typing a rare conjunct such as `ट्ट` perfectly still produced
  a wrong speed score, because the halant between the two consonants was counted as a
  letter of its own.

## Notes

- **Speed scores on practice containing these letters are lower than in v1.0.** This is
  the fix working, not a new problem: typing one rare letter perfectly used to be
  credited for three letters, which inflated the score. Correcting it necessarily
  lowers it.
- Stored scores are not recalculated, so a progress trend crossing this release shows
  a step down. That step is the correction, not lost progress. Nothing needs to be
  migrated or retyped.
- Eight keys that begin a rare letter (`ङ`, `ट`, `ठ`, `ड`, `द`, `ह`, `र`, and the half
  form `ह्`) now wait one keystroke to see whether a rare letter follows. Normal typing
  is unaffected, because the letter appears as soon as you press the key. If you
  mistype one of those letters and then press space, the pending keys are dropped and
  the space counts as a miss.
- Stored shapes stay at schema version 1; no migration in this release.
- No accounts, no cloud sync, no network calls.
