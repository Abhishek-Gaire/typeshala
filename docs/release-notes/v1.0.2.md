# Typeshala v1.0.2 — Release notes

**Version**: 1.0.2
**Date**: 2026-10-10
**Systems**: Windows, macOS, Linux (same bundle set as v1.0)

## What is new

- The app now shows the version it is actually running. Open **Options** and look at the
  new **About** group at the bottom, or open **Help → About Typeshala**. Both show the
  same number, and it is the one baked into the build you downloaded, not a typed in
  string that can drift out of date.
- A **Get updates** button sits next to that version. It opens the download page in your
  normal browser, so finding a newer build does not mean searching for the website.
- Both are available in English and Nepali.

## Fixed

- The About dialog used to claim version 1.0.0 on every build since 1.0.0, including the
  1.0.1 you may have downloaded. It now reports the real version.

## Notes

- **Get updates does not check for an update.** It opens the download page and you decide.
  The app cannot tell you whether a newer version exists, because doing that would need a
  published feed file and a code signing key we have to keep safe forever. We judged that
  a poor trade for a typing tutor, so updates stay a manual install, same as before.
- To update: download the installer for your system from the download page, run it, and
  your lessons, settings, and progress carry over untouched.
- Stored shapes stay at schema version 1; no migration in this release.
- No accounts, no cloud sync, no network calls. The app works fully offline, and the new
  button hands the address to your operating system rather than fetching anything itself.
