# Typeshala v1.0.2 — Release notes

**Version**: 1.0.2
**Date**: 2026-10-10
**Systems**: Windows, macOS, Linux (same bundle set as v1.0)

## What is new

- **Nepali Romanized now works in the classic practice screens.** Until now you could
  pick Nepali Romanized in Settings, but it silently drilled English letters. The
  engine had been lost in the rework of the practice screens. It is back, and you can
  type Devanagari drills with roman keys exactly like the other two layouts: the same
  Home, Top, Bottom, All, Game, and Free screens, the same three levels, the same
  keyboard guidance, and results that save the same way.
- **A third layout button in the practice toolbar.** The toolbar had two controls,
  English and Nepali Traditional. It now has a third, **अ**, for Nepali Romanized,
  right where you would expect it. Switching from the toolbar switches the whole shell,
  the same as the other two.
- **Twelve new Romanized drill rows.** Four screens times three levels, generated from
  the same roman map the rest of the layout uses, so they stay consistent with the
  English and Traditional rows as the map is corrected. They pass the same difficulty
  check and the same snapshot as everything else.
- **The app now shows the version it is actually running.** Open **Options** and look at
  the new **About** group at the bottom, or open **Help → About Typeshala**. Both show
  the same number, read from your build rather than typed into a string that can drift.
- **A Get updates button** sits next to that version. It opens the download page in your
  normal browser, so finding a newer build does not mean searching for the website.
- All new text is available in English and Nepali.

## Fixed

- The About dialog claimed version 1.0.0 on every build since 1.0.0, including the
  1.0.1 you may have downloaded. It now reports the real version.
- The three layout buttons in the toolbar had English tooltips baked in, so a Nepali
  user saw "Nepali" and "English" no matter which language the app was set to. They are
  localized now, and each button has a proper accessible label for screen readers.

## Notes

- **If you had Nepali Romanized selected in Settings, you were practising English.**
  The setting was saved and honoured, but the practice screens behind it were the
  English ones. They are the Romanized ones now. Nothing you have saved changes, and no
  past result is recalculated; only what you practise from now on is different.
- **Get updates does not check for an update.** It opens the download page and you
  decide. Telling you whether a newer version exists would need a published feed file
  plus a code signing key we would have to keep safe forever. We judged that a poor
  trade for a typing tutor, so updates stay a manual install, same as before.
- To update: download the installer for your system from the download page, run it, and
  your lessons, settings, and progress carry over untouched.
- **Two Romanized gaps remain, on purpose.** The Free screen echoes raw key presses in
  every layout, and the bonus Ramayana game still cannot be typed in Romanized. Parity
  is real across the practice path and absent in those two corners. Both are tracked.
- A Romanized row screen groups by the first key you press, so it keeps every letter
  reachable, but a row screen can also train the follow on keys from other rows. It is
  not finger pure the way the English row screens are.
- Stored shapes stay at schema version 1; no migration in this release.
- No accounts, no cloud sync, no network calls. The app works fully offline, and the new
  button hands the address to your operating system rather than fetching anything itself.
